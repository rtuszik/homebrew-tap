# Rtuszik Tap

## How do I install these formulae?

`brew install rtuszik/tap/<formula>`

Or `brew tap rtuszik/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rtuszik/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
